# Origin 1.0 context

Origin is a stable, topic-agnostic starting point for projects that combine a local browser
dashboard with a CLI-agent harness. Its distributed dashboard is intentionally empty. Users and
their agents cultivate pages and capabilities from their own context rather than deleting someone
else's assumptions.

Origin 1.0 contains one feedback-driven work loop and a repository-native wiki. It is single-user
and clone-local by implementation, while keeping storage, transport, and identity concerns separable
for later team variants.

The dashboard is a human interaction surface over the repository and harness. It is not itself the
agent, the source of authority, or a canonical database.

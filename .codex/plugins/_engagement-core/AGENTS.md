# Neutral engagement core

This is shared infrastructure, not a third communication channel. Accept an explicit channel scope;
string roots preserve dashboard compatibility. Never import either channel plugin. Keep lifecycle,
journal validation, atomic mutation, association, PR work-unit references and continuation rules
here. Each channel gets separate state and journals. A review requires exactly one canonical PR;
resolution requires observed GitHub merge evidence from an owner surface. Preserve historical
dashboard ledger paths and one-time legacy pause migration. Tests must prove independent removal,
active-state voting, stale-review rejection and merge verification.

# Web-to-CLI Handoff Packet template

Copy this file to `ONBOARDING_HANDOFF.md` only when a web agent has prepared it, the user has
reviewed it, and the user has authorized writing it to the project.

## Identity and provenance

Project label, creation time, source environment, Hadosh syllabus version, authoring agent, and
evidence labels for direct user statement, accepted decision, interpretation, or unresolved idea.

## Current journey state

Current phase, completed gates and evidence, work in progress, next action, and acceptance criteria.

## Asset Charter and user vocabulary

Asset promise, immediate and compounding value, the user's own terminology, and concepts already
made usable.

## Decisions, privacy, and authority

Accepted, rejected, deferred, and superseded decisions; protected information; permissions; and
actions still requiring approval. Never include secret values.

## Environment and Academy consultation

Repository, branch, operating system, dashboard/harness roles, intended web/CLI coordination, exact
Hadosh resources consulted, dates, maturity, extracted patterns, and local adaptations.

## Open state and recovery

Questions, blockers, risks, failed attempts, contradictions, smallest next action, packet location,
versioning, and recovery instructions.

## Receiving-agent receipt

The CLI agent records what it loaded, actual repository state inspected, its user-facing summary,
corrections, unresolved differences, reconfirmed authority, and the accepted next action before
implementation begins.

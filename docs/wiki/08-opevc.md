# OPEVC Work

OPEVC is a phased method for substantial agent work. Origin 1.0 does not ship a phase engine; this
chapter documents the pattern that mature projects can add.

## Observe

Reconstruct current reality. Read applicable instructions, inspect source and state, separate user
rulings from proposals, and record uncertainty before changing the system.

## Plan

Freeze a finite objective, boundaries, outputs, risks, and verification. A plan is not a list of
vague intentions; it closes the choices that Execute should not invent.

## Execute

Apply the approved bounded change. Record deviations and newly discovered work without allowing side
issues to replace the focused deliverable.

## Verify

Test the actual behavior, including failure paths, recovery, user-visible state, and integration
boundaries. Source presence is not runtime proof.

## Condense

Preserve the result, promote reusable learning, disposition deferred notes, and improve the
operating method when evidence shows that its instructions were weak.

Movement is not always forward. A later phase that disproves an earlier premise should reopen the
owning phase while preserving prior evidence rather than erasing history.
